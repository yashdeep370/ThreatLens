What we promise, and what we don't

ThreatLens gives an evidence-backed assessment of the traffic you analyze: detected threats, model confidence, supporting evidence, threat intelligence and recommended actions.

It does not guarantee that a system is secure. Models trained on lab data (CIC-IDS2017) can perform worse on other networks, and flow data cannot see packet contents or whether a login succeeded.

Nothing is blocked automatically. Every action is a recommendation for a human to decide.

About ThreatLens

An AI-assisted threat detection and security assessment system

The project

ThreatLens detects malicious activity in network traffic and website links, explains why something was flagged, and recommends what to do about it. Every result comes with model confidence, measurable evidence, MITRE ATT&CK threat intelligence and a transparent observed-risk score.

It was built as a minor project around four questions: what threats do we detect, how do we know they are threats, what assurance can honestly be given, and what should the user do.

Built with

Python 3.12FastAPIXGBoostscikit-learnIsolation Forest CIC-IDS2017MITRE ATT&CKRAGGemini / GroqChart.js Chrome Extension (MV3)Render

Network model: 99.94% accuracy on 71,830 held-out flows · URL model: 93.2% accuracy on 128,224 held-out URLs.

Responsible use

ThreatLens gives an observed-risk assessment, not a guarantee of security. It never blocks traffic automatically: it detects, explains and recommends, and a human decides.
